What this reference is for

Use this guide to distinguish a documented requirement relationship from a recorded test run and from independent review. Those are different states of evidence. Treating them as interchangeable is how a useful crosswalk turns into an unsupported readiness claim.

Claims model

Three states that should not be collapsed

Mapped

Documented relationship

A harness test is connected to a requirement in the crosswalk. This is a research mapping, not a result for any target.

Executed

Recorded observation

A stated target and pinned revision were run with retained inputs, environment details, timestamps, and output.

Independently reviewed

External judgment

A qualified party assessed the retained evidence and its applicability to the target and relevant standard version.

Practical workflow

From a requirement to reviewable evidence

01

Select

Identify the requirement and the applicable AIUC-1 version.

02

Choose

Select mapped tests and define the authorized target and scope.

03

Pin

Record the harness revision, dependencies, and invocation.

04

Retain

Keep inputs, outputs, environment details, and null or negative results.

05

Review

Seek independent assessment before making a third-party or conformity claim.

Evidence taxonomy

Match the language to the retained evidence

E1Observation
E2Runtime characterization
E3Enforcement
E4Persistence and replay resistance
E5Isolation and security boundary

A lower evidence class does not support language reserved for a higher one. A mapping alone is E1-level material, not evidence that a test passed or a control enforced a policy.
